# 水洗标排版与交付规范

此文件是项目内部质量标准，不是ISO认证声明。具体客户模板与有效HOUSE RULE有不同要求时，以经核实的客户要求为准，并记录适用范围。

## 1. 洗护符号

- 按水洗、漂白、干燥、熨烫、专业护理的规则顺序排列。
- 同一行使用统一尺寸的图标单元格、统一线宽、固定间距和居中布局。当前生成器以3.5×3.5mm单元格为基准；调整须整行协调。
- 对齐主体的视觉中心和底线，不能只检查SVG外框相同。圆、方、三角、熨斗和洗涤槽主体须有协调的视觉尺度，不能一个明显偏大或偏小。
- 洗涤槽下方工艺横线、禁止交叉线等附加笔画必须完整保留，并为其预留空间；不得为对齐而删线、裁切、拉伸或改变点数。
- 保持纵横比，禁止非等比缩放。符号之间不得相碰，与上下文字之间至少保留清晰空白；内部默认最小净空1mm，客户参考要求更大时使用参考值。
- 点数、横线数、交叉线及温度必须与选择的规则一致。图形大小一致不能代替语义检查。

## 2. 字体、比例与文字段落

- 使用客户模板已测量的字体、字号和行距；同一语言段不得无依据混用字体、字重或字距。
- 成分、装饰除外、洗护正文、符号、产地及注册/追踪信息分为清楚的层级；不能连成一整块。
- 成分与洗护之间保留固定最小间隔。现用AE内部基准为3mm；不能用剩余空间填充分隔，导致内容增加时空白消失。
- 装饰除外紧随成分，三语同步显示/隐藏；它与成分、正文的间距应协调，不与任一行重叠。
- 文本居中应按同一内容栏对齐。不得凭手输空格实现居中；不添加任意字符间空格。长词、地址和追踪码均须检查越界。
- 合理断行，避免温度与单位、数字与百分号拆开；不为排版擅改HOUSE RULE文字或标点。

## 3. 边距与分区

- 文字和符号必须在内容安全区内，当前AE左右各2mm为内部基准。不能贴外框、折线或缝口。
- 第一、第二部分的内容归属固定，英法和西文/进口商分区不得互相串入。
- 资料增多时允许对应区块和标签自然加长，不自动缩字、不挤掉段间距、不裁切内容。显示最终实际长度。
- 外框、分隔线使用统一线宽、色彩与虚线节奏。辅助线是否打印按用户选定模板要求执行，不能未经说明自行隐藏或更改。
- 号码、产地、追踪码和地址不能压线。区块末行与分隔线至少有清晰净空，内部默认最小1mm。

## 4. 实际尺寸与预览

- 宽度、长度、缝口使用毫米定义；当前用户指定AE PDF参考为28mm宽、100mm基础长度、两端各8mm缝口，内容可使长度增加。
- 屏幕放大只用于阅读，不改变打印尺寸。打印/导出保持100%，不使用适应页面缩放。
- 每页最多5张按实际标签计数，AE一组两张分别计数；任何标签不得跨页截断。超长标签放不下时明确提示。

## 5. 交付检查（逐行执行）

1. 核对款式、季度、供应商、PO年月、成分及装饰除外适用性；未给信息不得伪造。
2. 三语逐条与HOUSE RULE同一行对照；检查缺失文字、点数、工艺横线、温度及禁用标志。
3. 按标识→成分→装饰除外→洗护每行→符号→产地→RN→追踪码→法文→西文→进口商顺序检查。
4. 放大检查符号主体的大小、中心线和底线；检查每个段落的字距、行距、左右边距、上下净空及折线位置。
5. 至少检查单行成分、多部位长成分两种情况；不重叠、不溢出、不缩字，内容仍在正确分区。
6. 检查最终PDF/打印预览的实际尺寸、分页、字体与符号。不能仅审源代码或文本抽取结果。
7. 重新打开最终交付文件并渲染核查；结果未通过就继续修复。注明实测范围，不把尚未实测的纸张输出称为已验收。
